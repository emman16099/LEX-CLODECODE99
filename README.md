# LEX-CLODECODE99

An AI **attention agent**: it helps a business earn, hold, and convert the
attention of the right people.

## Build stages

1. **Purpose** (current) — the agent learns *why* it exists. See [PURPOSE.md](PURPOSE.md).
2. Knowledge — examples of hooks, ads and content that worked (and failed).
3. Skills — writing hooks, scripts, ads; checking results.
4. Feedback loop — reading real numbers and improving.
